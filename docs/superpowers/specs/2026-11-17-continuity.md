# Continuous development memory

Approved scope: preserve goal, architecture, decisions, verified progress and next action across chats; protect working code; archive closed failed experiments without hiding unresolved defects; combine bounded context, graph and local semantic retrieval.

Sources remain MISSION, STATE and project documents. Checkpoints and SQLite indexes are derived and disposable. No project schema migration, automatic remote embedding calls or background jobs. Archive is reversible metadata, not deletion. Mandatory goal, constraints and blockers survive budget overflow. Existing permissions are not renewed by recovery.

Three increments: (1) checkpoint, freshness and context budget; (2) indexed sources, explicit graph and archive; (3) local embeddings and measured retrieval. Embedding identity includes model, dimensions and chunk version. Changed sources invalidate dependent summaries and vectors. Core works without optional dependencies.

Acceptance: fresh-chat continuation, dirty worktree and branch changes, stale source exclusion, archive opt-in, active negative lessons, regression-test preservation, corrupt-index fallback, mandatory-context overflow and real local embedding retrieval. No promised percentage of savings or automatic prevention of regressions.
