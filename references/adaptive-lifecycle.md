# Пропорциональный процесс

| Profile | Когда | Минимум |
|---|---|---|
| QUICK | Correction / обратимый эксперимент | Цель, ограниченная область, короткий BUILD_LOG, targeted checks |
| STANDARD | Новый MVP / следующий increment | Рассмотренная миссия, один план/контракт, реальные проверки, feedback |
| FULL | Взаимозависимые подсистемы / важный контракт | Concept/architecture reviews, зависимости, регрессии |
| CRITICAL | Конкретный пакет с деньгами, PII, продакшеном, необратимостью | Current authority, rollback, усиленное evidence, независимый review когда разрешён |

3.0 STANDARD допустим с первого запуска. Рекламный API в будущем продукте не делает правку документа CRITICAL. Ограничивай конкретную операцию, не будущие функции. Меняй профиль через state.py set-profile с обоснованием и источником решения.

Не строй платформу ради гипотетического масштабирования. Сохрани минимальные seams: домен/интеграции, конфигурация владельца отдельно от механизма, переносимые данные. Другие пользователи и SaaS — следующие проверяемые increments.

Legacy 2.1 до upgrade требует approved concept/architecture/roadmap для QUICK/STANDARD. 3.0 не отменяет project-owned запреты молча: покажи источник и предложи отдельную корректировку устаревшего решения.
