# Короткая шпаргалка BPMN

- Кружок — событие: что запускает, прерывает или завершает процесс.
- Скруглённый прямоугольник — действие человека или системы.
- Ромб — решение или разделение/объединение путей.
- Pool — самостоятельный участник, организация или система.
- Lane — роль внутри участника.
- Сплошная стрелка — последовательность действий внутри pool.
- Пунктирная Message Flow — сообщение между разными участниками/pools.

## Как показать Codex изменение

1. Откройте `.bpmn` в Camunda Modeler.
2. Измените процесс визуально.
3. Сохраните файл, не меняя IDs без необходимости.
4. Напишите: `$project-master process sync PROC-XXX`.

Codex проверит XML, сопоставит изменение с sidecar, requirements, architecture и roadmap, сохранив layout. Существенный конфликт будет вынесен в Change Control.
